# Sefidel Tap-impure

## How do I install these formulae?

`brew install sefidel/tap-impure/<formula>`

Or `brew tap sefidel/tap-impure` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sefidel/tap-impure"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
